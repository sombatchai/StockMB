# 🛒 StockMB - Desktop Stock & Sales Management System

โปรแกรมบริหารจัดการสต็อกสินค้า พนักงาน และระบบขายหน้าร้าน (POS) พัฒนาด้วย Electron, JavaScript และ SQLite

## 🚀 Key Features
- 🔐 **Authentication:** ระบบเข้าสู่ระบบตามสิทธิ์ (Admin / Staff)
- 👥 **Employee Management:** เพิ่ม ลบ แก้ไข ข้อมูลพนักงาน
- 📦 **Product & Inventory:** จัดการสินค้าและตัดสต็อกอัตโนมัติ
- 📊 **Dashboard & Analytics:** สรุปรายรับ-รายจ่ายและยอดขาย

## 🛠️ Tech Stack
- **Desktop Framework:** Electron.js, Node.js
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite3
