**ระบบบริหารคลังสินค้าแบบพื้นฐาน** — โปรแกรมเดสก์ท็อปสำหรับร้านค้าขนาดเล็กถึงขนาดกลาง ใช้จัดการสินค้าคงคลัง ขายสินค้าหน้าร้าน ดูแลข้อมูลพนักงาน และดูรายงานสรุปยอดขาย/ต้นทุนเป็นกราฟ ในที่เดียว

##  ที่มาของโปรเจค

ร้านค้าจำนวนมากยังจดสต็อกด้วยมือหรือใช้ไฟล์ Excel ทำให้ยอดคงเหลือไม่ตรง สินค้าหมดโดยไม่รู้ตัว หรือสั่งซื้อซ้ำโดยไม่จำเป็น และเจ้าของร้านไม่มีข้อมูลสรุปที่ดีพอสำหรับตัดสินใจ

StockMB จึงรวบรวมงานหลักของร้านไว้ในระบบเดียว ตั้งแต่ **นำเข้าสินค้า → ขายออก → ตัดสต็อกอัตโนมัติ → สรุปรายงาน** เพื่อให้ข้อมูลเป็นปัจจุบันและลดความผิดพลาด

**วัตถุประสงค์**
- จัดเก็บข้อมูลและติดตามปริมาณสินค้าคงคลังได้อย่างเป็นระบบ
- แสดงรายงานสรุปสินค้าเข้า–ออก และสถานะสต็อกแบบเรียลไทม์ เพื่อช่วยเจ้าของร้านตัดสินใจ
- กำหนดสิทธิ์การเข้าถึงข้อมูลตามระดับผู้ใช้งาน เพื่อความปลอดภัยของข้อมูล (สอดคล้อง PDPA)
- ลดข้อผิดพลาดในการตรวจสต็อกและการสั่งซื้อซ้ำ

##  ฟีเจอร์หลัก

| เมนู | ทำอะไรได้บ้าง |
|---|---|
|  **Login System** | เข้าสู่ระบบด้วย Username / Password (ไม่มีการสมัครเอง บัญชีถูกสร้างโดยผู้ดูแล) · ลืมรหัสผ่านด้วยการยืนยันอีเมลที่อยู่ในระบบ · เปิด/ปิดสถานะบัญชีได้ |
|  **Dashboard** | กราฟรายรับจากการขายและต้นทุนนำเข้า · กราฟรายจ่าย (ค่าสินค้า + เงินเดือนพนักงาน) · ดูได้แบบรายวัน / รายเดือน / รายปี · ประวัติการขายและการนำเข้า ระบุจำนวน ผู้ทำรายการ และวันเวลา · สถิติรายสินค้า |
|  **Product Sales** | เลือกสินค้าใส่ตะกร้า ปรับจำนวน ยกเลิกรายการ แล้วกดชำระเงิน — ระบบบันทึกการขายและตัดสต็อกให้อัตโนมัติ |
|  **Product Management** | เพิ่ม / แก้ไข / ลบสินค้า (รูป, รหัส, ชื่อ, หมวดหมู่, ราคา) · เติมจำนวนสต็อกพร้อมบันทึกต้นทุน · **นำเข้าสินค้าทีละหลายรายการจากไฟล์ Excel** · ค้นหาด้วยรหัสหรือชื่อ |
|  **Employee Data** *(Admin)* | เพิ่ม / แก้ไขข้อมูลพนักงาน เช่น ตำแหน่ง เงินเดือน อีเมล บัญชีผู้ใช้ และสถานะการใช้งาน |

### ผู้ใช้งานในระบบ

| บทบาท | สิทธิ์ |
|---|---|
| **เจ้าของร้าน (Owner / Admin)** | ใช้งานได้ทุกเมนู รวมถึงรายงานทั้งหมดและข้อมูลพนักงาน |
| **พนักงาน (Staff)** | ขายสินค้า บันทึกรับเข้า และอัปเดตสต็อก — เข้าได้เฉพาะหน้าที่ได้รับสิทธิ์ |

> ขอบเขต: ระบบออกแบบมาสำหรับ **การขายหน้าร้านบน PC** ไม่รองรับการสั่งซื้อออนไลน์จากลูกค้า และไม่เชื่อมต่อระบบบัญชีภายนอก

##  เทคโนโลยีที่ใช้

- **Electron** — โปรแกรมเดสก์ท็อป (main process ใน `main.js`, สื่อสารกับหน้าจอผ่าน IPC)
- **SQLite** (`sqlite3` สำหรับ Node.js) — ฐานข้อมูลภายในเครื่อง ใช้ Transaction ตอนนำเข้าข้อมูลจำนวนมาก
- **HTML / CSS / JavaScript** — หน้าจอผู้ใช้ เช่น `Productmanagement.html`, `productsales.js`

### แนวคิด OOP และโครงสร้างข้อมูลที่ประยุกต์ใช้

| แนวคิด | ตัวอย่างในโปรเจค |
|---|---|
| **Inheritance** | `TimeDisplay.js` เป็นคลาสแม่สำหรับแสดงเวลาภาษาไทยให้หน้าอื่นสืบทอด · `auth.js` ให้ Staff สืบทอดจากพนักงานทั่วไปแล้วเพิ่มกฎการเข้าถึงหน้า |
| **Polymorphism** | `main.js` มีจุดเรียกเดียวที่คืนสถิติต่างกันตามหน้าจอ (ยอดขาย, ต้นทุน, เงินเดือน) |
| **Aggregation** | ตะกร้าสินค้าใน `productsales.js` รวมสินค้าไว้ชั่วคราว ลบออกจากตะกร้าแล้วข้อมูลสินค้าหลักยังอยู่ |
| **Composition** | ประวัติการขาย (`sales_history`) ต้องผูกกับรหัสสินค้าที่มีอยู่จริงเท่านั้น |
| **File Input** | นำเข้าสินค้าจาก Excel ผ่าน `import-products-bulk` พร้อมตรวจสอบข้อมูลก่อนบันทึก |
| **Sorting** | เรียงประวัติขาย/นำเข้าล่าสุดไว้บนสุด (`ORDER BY ... DESC`) · เรียงสินค้าตามราคาเมื่อค้นหา |
| **Searching** | `filterProductTable()` ค้นหาพร้อมกันทั้งรหัสและชื่อสินค้า ไม่สนตัวพิมพ์เล็ก/ใหญ่ |

ขนาดโปรแกรม: 12 คลาส, 33 เมธอด
